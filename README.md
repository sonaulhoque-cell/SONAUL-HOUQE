# Your Business Website

A beginner-friendly, responsive business website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — colours, layout and mobile styling
- `script.js` — mobile menu, current year and WhatsApp contact form

## Run the website
1. Download and extract this ZIP file.
2. Open the `business-website` folder.
3. Double-click `index.html`. It should open in your web browser.
4. To edit the website, open the folder in a code editor such as Visual Studio Code.
5. Save your changes and refresh the browser.

No installation, server or build process is required for this starter website.

## Important: personalise these placeholders
Open `index.html` and replace:
- `Your Business Name` with your business name.
- The About Us paragraph with your company details.
- `Service One`, `Service Two`, `Service Three` and their descriptions.
- `+91 00000 00000`, `hello@example.com` and the office address.
- The Facebook, Instagram and LinkedIn URLs with your actual profile links.

Open `script.js` and replace:
- `WHATSAPP_NUMBER = "910000000000"` with your WhatsApp number in international format.
- Use digits only: country code + phone number, without `+`, spaces or dashes.
  Example format for an Indian number: `919876543210`.

Also update the WhatsApp floating button URL in `index.html`:
- Find `https://wa.me/910000000000`
- Replace the digits with the same number you used in `script.js`.

## How the contact form works
The form validates the required fields and opens WhatsApp with a pre-filled message. The visitor must press Send in WhatsApp. This starter website does not send email or save form submissions to a database. For a form that stores enquiries or sends email automatically, you will need a backend or a form service.

## Publishing online
You can publish the folder using a static hosting service such as GitHub Pages, Netlify or your web hosting provider. Upload the three website files (`index.html`, `style.css`, `script.js`) while keeping them in the same folder.
